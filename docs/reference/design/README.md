# Växa Design Reference Pack

Use `../../ux/DESIGN_SYSTEM.md` as the main human/AI-readable design specification.

Use:
- `design-tokens.css` in this directory for CSS variables and core component primitives.
- `design-tokens.json` in this directory for machine-readable design tokens.
- `Vaxa_Dashboard_High_Fidelity_Preview.html` in this directory as the visual reference implementation.

Recommended instruction for Codex/Cursor:

> Read DESIGN_SYSTEM.md before implementing UI. Treat the design tokens and dashboard HTML as the source reference for the visual system. Reuse tokens and shared components. Do not substitute generic Tailwind colors, spacing, radii, or SaaS dashboard patterns.
