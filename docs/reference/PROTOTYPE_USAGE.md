# Prototype Usage

The HTML files in this folder are high-fidelity visual references created during discovery.

They are **not** the source of truth for domain logic, data architecture, or final routes.

Use them to evaluate:
- information hierarchy
- density
- production-floor interaction
- dashboard composition
- stage-specific list presentation

Current references:
- `402_Team_Dashboard_High_Fidelity_v0.3.html`
- `402_Production_Workflows_High_Fidelity_v0.4.html`
- `Main_Dashboard_High_Fidelity_Reference.html`

The UI can and should evolve as real implementation reveals friction.
